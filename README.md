A program that writes one 100-word monologue, spoken by a fantasy villain who is secretly just very tired, to `/output/entry.txt`.

The Dark Lord has conquered eleven kingdoms, pawned the real crown jewel to pay his dragon's dental work, and now offers the hero the crown, the map and the leaking east wing — in exchange for the library, the good chair, and one quiet evening a week. The tiredness is never announced; it lives in the pauses, the cat's cushion nobody has the staff to move, and the sting of the last line.

## Run

```sh
node main.ts
# writes entry.txt to /output (or $MAKEFUN_OUTPUT_DIR)
```

## Entry

`main.ts` — the program. It writes the monologue (exactly 100 words) to `entry.txt`.
